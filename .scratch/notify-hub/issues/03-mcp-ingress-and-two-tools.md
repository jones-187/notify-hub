# 03: MCP 入口与两个工具

**What to build:** pi 通过远程 MCP 连上服务。AI 能立刻发一条消息，也能排一条带绝对时间的消息。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 服务提供一个 streamable HTTP 的 MCP 端点（路径 `/mcp`）。这个端口只挂 MCP，不挂内网接口。
- [ ] 公网端口不响应内网接口（例如 `/notify` 返回 404）；内网端口不挂 MCP。
- [ ] 内网端口提供只读的 `GET /messages`，能看到未发与最近已发的消息，方便排查。
- [ ] 有一个启动入口，一次把两个端口和后台排期循环都起起来。
- [ ] 请求必须带 bearer 令牌，否则返回 401。
- [ ] 工具 `send_message`：给标题和正文，立刻发出，返回消息编号。
- [ ] 工具 `schedule_message`：给标题、正文和发送时间（带时区的 RFC3339，例如 `2026-10-13T08:00:00+08:00`），排期，返回消息编号。
- [ ] 发送时间落在过去时返回明确错误，不静默改成“现在发”。
- [ ] 两个工具的说明文字写清参数含义和时间格式，让 AI 不用猜。
