# 02: 排期表与到点发送

**What to build:** 排一条未来时间的消息。到点后它自动发出。服务重启后，这条消息仍然会发。

**Blocked by:** 01

**Status:** done（提交 d9f13d1）

- [ ] 有消息记录表：编号、标题、正文、通道集合、发送时间、状态（未发 / 已发 / 失败 / 已取消）、创建时间、尝试次数、最后错误。
- [ ] 后台每秒检查一次到期的消息，一次最多取 50 条。
- [ ] 到点后消息被送出，状态变成“已发”。
- [ ] 服务重启后，未发的消息按原定时间继续发出。
- [ ] 测试用可替换的时钟：把“现在”设到某一刻，再推进几秒，断言消息发出，不真等时间。
