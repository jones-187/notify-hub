# 01: 内网通知接口打通

**What to build:** 在内网，用一条带令牌的 HTTP 请求发一条消息，消息立刻送到所有已启用的通道。通道的连接地址从数据库的通道表里读，所以先用一条假地址也能把流程跑通；真地址在部署时填。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 服务提供一个“立刻发一条消息”的内网接口，参数是标题和正文。
- [ ] 没有令牌或令牌错误时返回 401；令牌正确时返回这条消息的编号。
- [ ] 消息会送到通道表里所有已启用的通道，并且每个通道的发送结果都被记下来。
- [ ] 通道的连接地址存在数据库里；换地址不需要改代码、不需要重建镜像。
- [ ] 有一个健康检查地址，只回一行 ok，不需要令牌，也不包含任何敏感信息。
- [ ] 有一条自动化测试：用假的通道出口，断言它收到了什么，绝不真的发消息到手机。
