# 对公网只暴露入口一个地址

排期数据、转发层（Apprise）和任何管理界面都不出内网。公网只能到达入口（MCP 端点），并且每次请求都必须带令牌。

理由：暴露面越小，令牌泄露或某个组件出漏洞时的影响越小。MIND 被否决的一部分原因就是它要求把整个网页应用暴露出去。

## 实现方式

服务在一个容器里开两个端口，用端口把边界做实，不只靠路径约定：

- **MCP 端口**：对公网。内网穿透只映射这一条。
- **内网端口**：给监控工具和脚本用的普通 HTTP 接口（`POST /notify`）、健康检查、状态查询。不映射到公网。

## Consequences

- 内网穿透（节点小宝）只映射 MCP 端口。监控工具在内网，走内网端口。
- 以后加界面时，默认放内网端口；要放公网必须另做决定。
- 容器里要维护两份路由注册，别把内网接口误挂到 MCP 端口上。
